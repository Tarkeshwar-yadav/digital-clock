# Digital Clock ⏰

A simple digital clock made with HTML, CSS, and JavaScript. It displays the current time in 12-hour format along with AM/PM and the full date including the weekday.

## Features

- 12-hour clock format with AM/PM
- Current time updates every second
- Displays weekday and full date (DD/MM/YYYY)
- Clean and minimal design
